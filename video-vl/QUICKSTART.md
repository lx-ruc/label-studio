# 快速开始指南

## 🚀 快速启动Streamlit应用

### 方法一：使用启动脚本（推荐）

```bash
cd /home/u20240148/project/video-vl
./run_streamlit.sh
```

### 方法二：直接使用Streamlit命令

```bash
cd /home/u20240148/project/video-vl
streamlit run streamlit_app.py
```

### 方法三：指定端口和地址

```bash
streamlit run streamlit_app.py --server.port 8501 --server.address 0.0.0.0
```

## 📝 使用步骤

1. **启动应用后**，浏览器会自动打开，或手动访问显示的URL（通常是 `http://localhost:8501`）

2. **加载模型**（首次使用）：
   - 在左侧边栏找到"配置"区域
   - 确认模型路径是否正确（默认：`/home/u20240148/project/Qwen2.5-VL/Qwenvl_72B`）
   - 点击"加载模型"按钮
   - 等待模型加载完成（可能需要几分钟，取决于模型大小和硬件）

3. **上传视频**：
   - 切换到"📤 视频上传与分析"标签页
   - 点击"选择视频文件"上传视频
   - 支持格式：MP4、AVI、MOV、MKV

4. **开始分析**：
   - 上传视频后，点击"开始分析"按钮
   - 等待分析完成（可能需要较长时间，取决于视频长度和复杂度）
   - 分析过程中会显示进度条

5. **查看结果**：
   - 分析完成后，切换到"📊 分析结果"标签页
   - 可以查看各个模块的详细分析结果
   - 支持下载JSON格式的完整分析结果

## 💡 提示

- **模型加载**：模型只需要加载一次，之后会保存在session中，刷新页面可能需要重新加载
- **视频大小**：建议视频文件不要过大，过大的视频可能需要更长的处理时间
- **GPU内存**：确保有足够的GPU内存（72B模型需要较大内存）
- **分析时间**：视频分析可能需要几分钟到十几分钟，请耐心等待

## 🔧 常见问题

### Q: 模型加载失败怎么办？
A: 检查模型路径是否正确，确保模型文件完整，检查GPU内存是否足够。

### Q: 分析过程中页面卡住了？
A: 这是正常的，模型推理需要时间。可以查看终端输出了解进度。

### Q: 如何查看完整的JSON结果？
A: 在"分析结果"标签页，切换到"完整JSON"子标签，或点击下载按钮保存JSON文件。

### Q: 可以同时分析多个视频吗？
A: 目前一次只能分析一个视频，分析完成后可以上传新的视频。

## 📞 技术支持

2. 模型路径是否正确
3. GPU内存是否充足
4. 视频格式是否支持
